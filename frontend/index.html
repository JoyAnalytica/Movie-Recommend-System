    About This Project

    MovieAI is a Machine Learning project that uses content-based recommendation: it compares movies by their features and suggests the closest matches to the title you enter. The model is served by a FastAPI backend, posters come from TMDB, and this interface is built with plain HTML, CSS and JavaScript.
